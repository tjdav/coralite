## Release Overview

`create-coralite` v1.2.0 updates all starter templates to [`coralite`](file:///home/thomas/Projects/coralite/packages/coralite/package.json) `^1.2.0`, delivering compile-time boolean and ARIA attribute reflection for zero-JS static HTML pages to newly scaffolded projects. This release also synchronizes template AI agent guidelines across all presets with the consolidated `window.__coralite__` runtime namespace.

---

### Key Highlights

#### Starter Template Alignment with Coralite v1.2.0

Starter templates now scaffold new projects against [`coralite`](file:///home/thomas/Projects/coralite/packages/coralite/package.json) `^1.2.0` by default. Newly initialized applications receive compile-time boolean and ARIA attribute reflection on static pages, removing falsy attributes from pre-rendered HTML without emitting client-side JavaScript.

* **Updated Dependencies**: [`packages/create-coralite/templates/css/package.json`](file:///home/thomas/Projects/coralite/packages/create-coralite/templates/css/package.json#L14), [`packages/create-coralite/templates/scss/package.json`](file:///home/thomas/Projects/coralite/packages/create-coralite/templates/scss/package.json#L14), and [`packages/create-coralite/templates/plugin/package.json`](file:///home/thomas/Projects/coralite/packages/create-coralite/templates/plugin/package.json#L21) upgrade the `coralite` development dependency from `^1.1.0` to `^1.2.0`.
* **Compile-Time Static Attribute Reflection**: New projects evaluate single-token attribute bindings (`{{ prop }}`) against HTML boolean and ARIA specifications during SSR, omitting falsy boolean attributes directly from the pre-rendered AST.
* **Deterministic Hydration**: Client runtimes perform direct DOM updates rather than full-tree token crawling, preserving zero-JS static baselines and reducing hydration overhead.

**Template Dependency (`package.json`)**

```diff
  "devDependencies": {
-   "coralite": "^1.1.0"
+   "coralite": "^1.2.0"
  }
```

**Scaffolded Page Static Output (`src/pages/index.html`)**

```html
<button disabled="{{ isDisabled }}" aria-expanded="{{ isExpanded }}">
  Action
</button>

<script type="module">
  export const meta = {
    isDisabled: false,
    isExpanded: false
  }
</script>

<!-- Compiled Static HTML Output (zero client JS): -->
<!-- <button aria-expanded="false">Action</button> -->
```

### Internal Changes

#### Template Agent Rules and Global Namespace Synchronization

Template AI agent instructions across the `agent`, `css`, `plugin`, and `scss` starter directories now align with the single `window.__coralite__` runtime global namespace invariant. Scaffolding documentation updates imperative SPA router lookups from the legacy global to the structured plugin domain.

* **Consolidated Router Lookup**: Agent guidelines in [`packages/create-coralite/templates/agent/AGENTS.md`](file:///home/thomas/Projects/coralite/packages/create-coralite/templates/agent/AGENTS.md#L223), [`packages/create-coralite/templates/css/AGENTS.md`](file:///home/thomas/Projects/coralite/packages/create-coralite/templates/css/AGENTS.md#L223), [`packages/create-coralite/templates/plugin/AGENTS.md`](file:///home/thomas/Projects/coralite/packages/create-coralite/templates/plugin/AGENTS.md#L223), and [`packages/create-coralite/templates/scss/AGENTS.md`](file:///home/thomas/Projects/coralite/packages/create-coralite/templates/scss/AGENTS.md#L223) replace `window.__coralite_router__` with [`window.__coralite__.plugins.router`](file:///home/thomas/Projects/coralite/packages/coralite/types/globals.js#L18).
* **Global Pollution Prevention**: Prohibits ad-hoc property attachments on `window` and `globalThis` in generated code, ensuring scaffolded projects maintain clean browser globals and deterministic testing sandboxes.

**Imperative SPA Router Access**

```javascript
// Before
const router = window.__coralite_router__

// After
const router = window.__coralite__.plugins.router
```
