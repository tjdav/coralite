## Release Overview

`create-coralite` v1.4.0 updates all project scaffolding templates to target `coralite` `^1.4.0` for compile-time static HTML generation.

---

### Internal Changes

#### Template Dependency Alignment

Updated the `coralite` devDependency from `^1.3.1` to `^1.4.0` across all starter templates so newly scaffolded projects install the latest framework release out of the box:

* CSS starter template ([packages/create-coralite/templates/css/package.json](https://github.com/tjdav/coralite/blob/main/packages/create-coralite/templates/css/package.json))
* SCSS starter template ([packages/create-coralite/templates/scss/package.json](https://github.com/tjdav/coralite/blob/main/packages/create-coralite/templates/scss/package.json))
* Plugin starter template ([packages/create-coralite/templates/plugin/package.json](https://github.com/tjdav/coralite/blob/main/packages/create-coralite/templates/plugin/package.json))
