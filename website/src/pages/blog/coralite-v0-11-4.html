Coralite v0.11.4

Coralite v0.11.4 improves text node compatibility, updates documentation alt text, and fixes asset paths for stability in static site generation. Learn more about the changes.

Thomas David June 21, 2025

Coralite’s v0.11.4 release introduces refinements to text node handling, documentation improvements, and minor updates for stability and clarity.

Core Functionality

  • Refactor: Handle non-array objects as arrays in text node replacement to improve compatibility with dynamic content rendering.
  • Fix: Corrected the path for an introductory GIF to ensure consistent asset loading across environments.

Documentation and Metadata

  • Updated README image alt text and added video description for improved accessibility and clarity in documentation.
  • Chore: Version bump to align with updated package metadata and release tagging practices.

Get the release

npm install coralite@0.11.4

For detailed information on all changes, refer to the git v0.11.4 changelog
