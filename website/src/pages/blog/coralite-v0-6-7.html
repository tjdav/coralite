Coralite v0.6.7

Coralite v0.6.7 introduces repository URL updates, licensing revisions, and version consistency improvements for developers using the HTML module static site generator. Learn more about key changes in this release

Thomas David March 23, 2025

Coralite’s latest release, v0.6.7, focuses on administrative updates and infrastructure improvements to enhance repository management, licensing clarity, and version consistency across development workflows.

Core Functionality

  • Updated the project’s repository URL for improved tracking and collaboration efficiency.
  • Revised the licensing model to align with current distribution policies and compliance standards.
  • Bumped version number to v0.6.7, ensuring consistent semantic versioning across module dependencies.

Get the release

npm install coralite@0.6.7

For detailed information on all changes, refer to the git v0.6.7 changelog
