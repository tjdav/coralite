server

Stable

Fetches data while the page is generated in Node. The block is stripped from the browser bundle and its return value becomes state.

Build time only.

server() runs during coralite build and in the development server's render pass. The compiler removes it from the module that ships to the browser, so credentials, database clients and absolute paths never reach a client.

Signature

export function server (context: CoraliteServerContext): | Record<string, any> | void | Promise<Record<string, any> | void> interface CoraliteServerContext { state: Record<string, any> route: CoraliteRoute root: object | null page?: CoralitePage session: CoraliteSession store?: any [pluginContext: string]: any }

The block may be synchronous or asynchronous. Returning a promise is the common case because file reads and HTTP calls are asynchronous.

Return value

The returned object is shallow-merged into component state, on top of attribute values. Each key becomes a flat template token and is available to getters. Returning nothing, or returning an empty object, leaves state untouched.

export async function server ({ state, route }) { const posts = await loadPosts() return { post: posts.find((post) => post.slug === route.params.slug), total: posts.length } } async function loadPosts () { const fs = await import('node:fs/promises') return JSON.parse(await fs.readFile('src/data/posts.json', 'utf8')) }

A non-object return value fails the build. Arrays are rejected too. Wrap a collection in a key: return { posts }, not return posts.

Fetching data

Load modules that only the server needs with a dynamic await import() inside the block. A static top-level import would be pulled into the component bundle, defeating the point of the boundary.

export async function server ({ state }) { const response = await fetch('https://api.github.com/repos/tjdav/coralite/releases/latest', { headers: { accept: 'application/vnd.github+json' } }) if (!response.ok) { throw new Error(`Release request failed: ${response.status}`) } const release = await response.json() return { release: { tag: release.tag_name, url: release.html_url } } }

Failures throw and stop the page render. When a failure is acceptable, catch it here and return a documented fallback state instead of letting the build break. A component-level onError boundary can also render fallback UI in production.

Serialization boundary

Everything assigned to state crosses into the hydration payload. Return plain data only: strings, numbers, booleans, arrays, plain objects and null. Functions, class instances, Map, Set, Date and cyclic references cannot be serialized.

const updated = new Date() return { publishedAt: updated.toISOString(), publishedLabel: updated.toLocaleDateString('en-GB') }

Convert once, in the block. Deriving a display string during render keeps the value stable and avoids repeating locale work in getters.

Determinism

A build must be reproducible: the same inputs produce byte-identical HTML. Do not read the wall clock, random values or mutable module state here. Inject dates, feature flags and test data through the page, a plugin or the global store, and keep the conversion inside server().

If content changes over time, that is cache invalidation, not rendering. Refresh it through the store or an incremental build rather than by calling Date.now() during a render.

Diagnostics

  • CORALITE-E401 reports request or response globals, which Coralite does not provide.
  • CORALITE-W401 reports state written by server() that nothing reads.
