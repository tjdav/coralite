API Reference

Every export, precisely specified.

The complete contract for components, pages, plugins, and the CLI. Each page documents one export, its signature, the context it receives, and the diagnostics that guard it.

Component API

Top-level named exports in src/components/<tag-name>.html.

attributes

Declare, coerce, and validate host HTML attributes into reactive state.

client

The browser runtime block: refs, events, observation, and cleanup.

server

Fetch data in Node.js at build time, then hydrate component state.

getters

Pure, synchronous derivations shared by the server and the browser.

style

Map reactive state onto host CSS custom properties.

slots

Intercept and transform projected child content before rendering.

formControl

Opt into native form association and constraint validation.

provide & consume

Share values with descendants through the W3C context protocol.

listStrategy

Choose between a full reactive update and a direct DOM patch for list changes.

onError

Render fallback markup when a component or page fails during the build.

Pages are thin orchestrators that compose components and define routes.

definePlugin

Inject context and extend behavior with the two-phase curried signature.

Develop, build, validate, and auto-fix with the coralite binary.
