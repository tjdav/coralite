client

Stable

The browser lifecycle block. Runs once per mounted instance and owns every listener, observer and timer the component creates.

Browser only.

client() is stripped from the server render and serialized into the component bundle. It runs after the element is connected and its markup is hydrated. Module scope is not shared with it, so anything from the module must be loaded with await import() inside the block.

Lifecycle and cleanup

The block runs once per mount. It is not re-invoked when state changes and it is not a render callback. The framework tears the instance down at disconnect; the contract is that everything the block creates is reachable from signal.

export function client ({ refs, signal }) { const button = refs('button') button.addEventListener('click', () => { console.log('clicked') }, { signal }) const frame = requestAnimationFrame(() => { console.log('first frame') }) signal.addEventListener('abort', () => cancelAnimationFrame(frame), { once: true }) }

Do not await updateComplete at the top of the block. The DOM is already settled when client() runs, and awaiting it there delays every later line by a microtask for no reason. Await it after mutating state, when the next step depends on measured layout.

export async function client ({ state, refs, signal, updateComplete }) { const panel = refs('panel') refs('expand').addEventListener('click', async () => { state.expanded = true await updateComplete panel.scrollIntoView({ block: 'nearest' }) }, { signal }) }

Observing state

observe is for effects that must run when a value changes: canvas repaints, third-party widgets, analytics. It is never for deriving state. Assigning state inside an observer is an infinite-loop hazard and is reported as CORALITE-E302; use a getter instead.

export function client ({ state, observe }) { observe('count', (value, previous) => { console.log('count changed from', previous, 'to', value) }) }

The returned disposer exists for conditional teardown. Normal cleanup is automatic at disconnect.

Events

emit wraps dispatchEvent with the framework defaults: bubbling, composed, and visible to ancestor light-DOM listeners. It returns false if a listener called preventDefault() on a cancelable event.

export function client ({ state, refs, signal, emit }) { refs('save').addEventListener('click', () => { const saved = emit('save', { value: state.value }, { cancelable: true }) if (saved) { state.dirty = false } }, { signal }) }

Serialization boundary

Top-level imports are not available inside client(). Referencing one is CORALITE-E301, because the server module graph is not shipped to the browser. Load the module locally instead:

export async function client ({ refs, signal }) { const { createChart } = await import('../utils/chart.js') const chart = createChart(refs('canvas')) signal.addEventListener('abort', () => chart.destroy(), { once: true }) }

Node globals such as process, Buffer and __dirname are CORALITE-E304. A .css import belongs here too, loaded with await import('pkg/styles.css') so the bundle can register the stylesheet; importing CSS at module scope is CORALITE-E109.

Diagnostics

  • CORALITE-E202 reports a refs() name that no template element declares.
  • CORALITE-E301 reports a module-scope import used inside the block.
  • CORALITE-E302 reports state mutated inside observe().
  • CORALITE-E304 reports a Node global in the browser block.
  • CORALITE-E109 reports a stylesheet import outside client().
