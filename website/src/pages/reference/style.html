style

Stable

Writes state into the host element's inline style. The escape hatch for values a stylesheet cannot know, such as measured sizes and user-chosen colors.

Build time and browser.

The server evaluates the block while rendering, so the first paint already carries the computed declaration. The browser re-applies it when tracked state changes, without re-rendering the template.

Signature

export const style: Record<string, string | number | ((context: CoraliteStyleContext) => any)> interface CoraliteStyleContext { state: Readonly<Record<string, any>> isServer: boolean signal: AbortSignal }

Keys are CSS property names. Standard properties accept camelCase and are normalized to kebab-case, so backgroundColor becomes background-color. Custom properties must start with -- and are written exactly as declared.

Context

Key Type Notes

Declarations

A declaration is a constant or a function. Functions run synchronously and must not read root, refs or slots: style is evaluated before the DOM exists on the server and outside the template update in the browser.

export const attributes = { accent: { type: String, default: '#06b6d4' }, density: { type: String, default: 'comfortable' } } export const style = { '--accent': ({ state }) => state.accent, '--stack-gap': ({ state }) => (state.density === 'compact' ? '4px' : '12px'), position: 'relative' }

Custom properties are the preferred output. They let one declaration drive any number of rules in the component stylesheet, including descendants that the host cannot target through inline style.

Nullish omission

Returning null, undefined, false or an empty string removes the declaration from the host style attribute. This makes conditional properties cheap: null means "not set", not "null" in the DOM.

export const style = { '--progress': ({ state }) => state.progress === 0 ? null : `${state.progress}%` }

Numbers are written without units, matching raw CSS. padding: 16 produces padding: 16;, which browsers ignore. Add the unit yourself or use a plain property such as zIndex where unitless values are valid.

Synchronous execution

Style is resolved before the template renders, so it cannot wait. An async function, or a function returning a promise, fails with CORALITE-E303. Load asynchronous data in server() and read the result from state.

export const style = { '--width': async ({ state }) => await measure(state) }
export const style = { '--width': ({ state }) => `${state.width}px` }

Parameter shape

Style functions take the context object. The older (state) => state.value form is migrated automatically by coralite fix and reported as CORALITE-E105.

Output

The server writes the resolved declarations into the host style attribute, so the first paint is correct without waiting for JavaScript. The functions themselves stay in the component bundle because the browser has to re-evaluate them on state changes.

Use this block for values, not for rules. A component's static rules belong in its <style> element, where they are scoped, deduplicated and shipped as CSS rather than inline markup.

Diagnostics

  • CORALITE-E303 reports an asynchronous style getter.
  • CORALITE-E105 reports the legacy single-parameter shape.
