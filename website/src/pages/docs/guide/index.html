Coralite Guide

Guide

Access detailed Coralite user guides for building websites using standard HTML, CSS, and JavaScript. No special syntax required.

Welcome to our guides. We've organized them to help you learn Coralite from the ground up.

1. Foundations

  • Getting Started

    Learn how to install Coralite, set up a project, author your first component and page, and run core scripts.

  • Authoring Pattern

    Master the unified block structure, context keys, template rules, and serialization boundaries across Coralite.

  • Quick Start (Installation)

    Learn how to install Coralite and bootstrap a new project quickly.

2. Core Concepts

  • Server-Side Rendering (SSR)

    Deep dive into Coralite's SSR architecture, server blocks, and performance patterns.

  • Components (Static & Dynamic)

    Master both static HTML-based components and dynamic components with reactive logic.

  • Managing the DOM (Refs)

    Learn how to easily target and manipulate DOM elements without querying.

  • Page Metadata

    Manage SEO tags and page-specific metadata securely with the built-in plugin.

  • Page Variables

    Understand the built-in path and URL context variables automatically injected into your pages.

  • Reactivity & Context

    Master fine-grained reactivity, signals, getters, async getters, observe, updateComplete, and context injection.

  • Styling & Slots

    Explore Light DOM CSS scoping, :host rewrites, reactive custom properties, slot projections, and slot transformations.

  • Opting Out with

    Keep code samples, third-party widgets, and authored markup literal while skipping tokens, compilation, hydration, validation, and controller extraction.

3. Advanced Guides

  • Self-Healing Code & Diagnostics

    Leverage static analysis, 1-shot AST auto-fixing, AI pair-programming rules, and strict CI gates.

  • Content Security Policy (CSP)

    Harden your applications with nonces, automated SHA-256 hashing, and external script bundling.

  • Client-Side JavaScript

    Dive deep into complex client-side interactions and lifecycle hooks.

  • Styling & CSS

    Master techniques for scoping styles and organizing your application's CSS.

  • Authoring Plugins

    Learn how to create powerful custom plugins to extend the Coralite framework.

  • Internationalization (i18n)

    Discover internationalization patterns including locale routing, message bundles, native Intl formatting, and RTL support.

  • Search Engine Optimization (SEO)

    Learn about built-in metadata extraction, plugin-driven sitemaps and RSS feeds, robots.txt, and SEO framework boundaries.

  • Handling Binary Assets

    Best practices for importing and managing images, fonts, and other static files.

  • SPA Router

    Build single-page applications on static output: outlets and persistent elements, guards, navigation events, and state that survives route swaps.

  • Building Applications

    Learn how to architect Coralite apps across Pure SSG, Hybrid data fetching, and SPA modes.

  • Testing & Deployment

    Comprehensive guide to unit testing, E2E testing with Playwright, static deployment, and CSP configuration.

  • E2E Testing & Hydration

    Learn how to test Coralite apps using Playwright or Cypress by waiting for hydration.
