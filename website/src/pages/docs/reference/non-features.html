Non-Features Reference

Reference

Comprehensive reference of intentionally omitted features in Coralite, their alternatives, and core design rationale.

Coralite deliberately does not do certain things. Each omitted feature has a standard Web Platform alternative or architectural rationale. The list of non-features is finite and stable.

Not provided Alternative Why
Shadow DOM Light DOM with @layer scoping Slot transparency and find-in-page work without encapsulation overhead
Virtual DOM Signal reactivity and direct DOM The framework updates only what changed, without a diff
Client-side router in core <a href> and View Transitions, or opt-in router plugin MPA navigation is faster and works without JavaScript
Route guards in core Router plugin's beforeEach Only opt-in SPA routing needs guards
Server-side middleware Plugin onBeforePageRender There is no runtime server, so there is no middleware chain
Sessions and authentication Client-side fetch from APIs The build output is the same for every visitor
SSR at request time Build-time SSG only Pages are files, not functions
Deno / Bun / edge adapters Node-only build The build pipeline uses Node-specific APIs
Hash routing Not supported The router is opt-in and history-based
Nested layouts (automatic) Explicit composition via slots Automatic layouts require route hierarchy the framework does not track
Prefetch API Browser prefetch on hover Browsers already do this
Shells for unknown params 404 Unenumerated dynamic params are not pages
Redirects in config Host config or __redirect marker Redirects are a deployment concern, not a build concern
Plural rule engines Intl.PluralRules The platform ships this
Locale detection Client-side or host routing There is no request to inspect
Sitemap generation in core Plugin pattern The list of pages is available to any plugin
Feed generation in core Plugin pattern Same reason as sitemap
Full a11y test suite Validator warnings plus author responsibility False positives in a11y tooling are worse than missed warnings
Template type checking via tsc AST validator plus Volar bridge tsc cannot parse .html natively
Proxy reactivity (removed in v1.0) Signals One reactivity model

If a feature appears in neither this table nor the documentation, it may be planned—check the roadmap.
