Built-in plugins

Some plugins are internal to the build. metadata and static-assets run automatically; testing runs in testing mode; refs is part of the component compiler. The SPA router is opt-in and must be registered in coralite.config.js.

  • refs System

    How template refs are stamped, scoped and resolved, including the guarantees that make existence guards unnecessary.

  • Metadata Plugin

    Extraction of <title>, <meta name> and lang into page.meta, including dynamic metadata components.

  • Static Assets Plugin

    Copying public/, configured assets and injected assets into the output with content tracking.

  • Testing Plugin

    Automatic data-testid generation and the hydration readiness hooks used by E2E tests.

  • Router Plugin

    The opt-in SPA router: outlet swap, client API, guards, navigation events and the fetch contract.

The router and the lists plugin are the two built-ins a project may enable explicitly. See Lists & Store for the store and list bindings.
