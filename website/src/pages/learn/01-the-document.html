The Document

Every application starts with a single HTML file. Before we add components or server logic, we must understand the platform.

The Boilerplate

The browser runtime is inherently a streaming document processor. All component boundaries in Coralite resolve down to standard semantic HTML, starting with the foundational <!DOCTYPE html> directive.

Coralite App

Hello, Platform.
Pro Tip: Native HTML is forgiving, but Coralite is strict. We validate your structure at build time to prevent hydration mismatches.

The <head> Tag

The <head> element is reserved for metadata, external style dependencies, and critical resource preloading.

The <body> Tag

The <body> acts as the root host for custom elements and progressive hydration targets.
