Theming with Variables

Build components that are infinitely customizable by consumers using CSS Custom Properties and Coralite's reactive style export.

Exposing Theme Tokens

Instead of hardcoding colors directly into your component's CSS, you should expose them as CSS custom properties (variables) with sensible fallbacks. This allows consumers to theme your component without rewriting your CSS.

:host { /* Expose variables with fallbacks */ --card-bg: var(--bg-card, #111827); --card-text: var(--text-primary, #F8FAFC); --card-border: var(--border-subtle, #1F2937); } .card { background: var(--card-bg); color: var(--card-text); border: 1px solid var(--card-border); padding: 24px; border-radius: 8px; }

Overriding from the Parent

Consumers can now override these variables directly on the host element, or from any parent container, using standard CSS.

Custom Theme

Reactive Theming with the style Export

Coralite takes this a step further with the style export. It allows you to reactively compute CSS variables based on the component's internal state.

Why this matters

This pattern eliminates the need for complex JavaScript theme providers or Context APIs. The browser's native CSS engine handles the styling, while Coralite handles the reactive state.
