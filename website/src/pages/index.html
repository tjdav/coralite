Fail-closed by design

The build is the first test.

Invalid templates, broken component contracts, and server code that leaks into the client stop the build — with an exact location and a suggested fix.

  • Fail closed. The build aborts with a non-zero exit. No runtime-only surprises.
  • Exact, not approximate. Code, file:line, source context, why it failed, and a one-shot fix where possible.
  • Machine-readable. Stable codes and JSON output for CI, scripts, and AI harnesses.

Built for agents. Deterministic errors let an agent repair in one pass instead of reverse-engineering a runtime stack trace.

Architectural Decisions

Coralite intentionally leaves out unnecessary abstractions, aligning directly with native browser mechanisms.

Explicit Boundaries

No class extends HTMLElement. Define behavior with standard top-level export function server() and export const attributes.

Clean Separation

Strict flat identifiers in HTML ({{ token }}). Logic is lifted to getters. No inline handlers or complex expressions.

Native Foundation

No Shadow DOM. Encapsulation is handled via CSS Scoping and @layer. Preserves native form association and accessible DOM structures.
